NORTH WAY - APP FILES
=====================

This folder is the app. It is published with GitHub Pages at https://northwaylb.com

Files
- index.html            the guide (Arabic, English and French)
- privacy.html          terms and privacy policy
- manifest.webmanifest  tells phones this is an installable app
- sw.js                 lets the guide open with no signal
- icon-*.png, apple-touch-icon.png   the app icon
- fonts/ photos/        fonts and your own photos

HOW TO UPDATE THE APP
1. Unzip the new version.
2. GitHub > your repository > Add file > Upload files.
3. Select all the files inside the unzipped folder and drag them in (not the zip itself).
4. Commit changes. Wait 1 to 2 minutes.
5. On the phone: close the app and open it twice.

Content (places, news, providers, contact details) is changed in the Google Sheet, not here.
