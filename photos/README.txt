PHOTOS
Put photo files here (jpg, png or webp), then name them in the app file like this:  imgs:["photos/qammouaa.jpg"]
Keep each photo under 200 KB (about 1200 pixels wide) so the app stays fast.
Only use photos you took yourself or have written permission to use, and write the owner's name in imgCredit.
For hotels and taxis managed in the Google Sheet, paste a direct https link to the image instead.
